**Profile:** quick (partial pass). **Scope:** shipping Next.js 16 app under `src/`, lockfile, GitHub Actions, plus a read of `archive/` to see whether it ships. **Budget:** unset. **Source ref:** `333e71dc2853af558192e7470dfcd6a09eada354` (`main`, clean). **Execution:** sandboxed source-and-local-only policy. Target-controlled execution was **not** run: this Cloud Agent VM cannot enforce the skill’s OS sandbox (empty allowlisted env, no egress, read-only target, scratch-only writes, promotion-safe descriptors). **Prior runs:** none.

This is not a complete-coverage claim. One hunter wave and one final critic-equivalent pass. Critic accepted no extra in-scope units; archive Next 14 / Vite 5 prototype trees were recorded as non-shipping.

## Security posture

Clerk plus per-query `userId` filters protect most track/version/theme/settings paths. SSRF on dynamic fetches is implemented and unit-tested. Uploads are type- and size-bounded. No committed live secrets. Gaps on the reviewed commit: several Server Actions skipped in-handler ownership (`chat`, `share`, `catholic` create, `ai-suggestions`), Next 16.2.11 / Vite 8.0.8 / hono 4.12.25 / undici 7.24.7 in the lockfile, no app rate limit, and public Blob URLs.

No records were `confirmed` (no bounded local exploit observation). Eleven `needs_validation` leads and three `rejected` claims. Low-risk source hardenings and the required dependency floors are applied in this PR (see Remediations).

## Confirmed findings

None. Severity is not assigned to `needs_validation` records.

## Hardening notes and positive patterns

- `safeFetch` / `assertPublicHttpUrl` used for theme URL ingest and provider audio download; IPv4-mapped IPv6 included; tests in `src/test/security_url.test.ts`.
- Upload extension+MIME+50MB+filename sanitize with tests.
- Most CRUD uses `requireUserId` + `requireOwnedTrack`/`requireOwnedVersion`.
- AES-256-GCM for BYOK keys; `.env` gitignored; gitleaks in CI; `contents: read` on main CI; comment `droid.yml` gated by `author_association`.
- No `dangerouslySetInnerHTML`; `X-Frame-Options: DENY`.
- `archive/` is a static snapshot (`archive/README.md`) excluded from tsconfig/eslint/CI. Next 14.2.35 there is **not shipped**. Prototype `vite ^5.2.0` has no 5.x patch; left in place and documented.
- axios and fast-xml-parser are absent from the lockfile.
